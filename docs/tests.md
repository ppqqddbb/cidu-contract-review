# 测试策略

- 单元测试：状态枚举、配置、Schema、任务领取逻辑。
- 集成测试：Alembic、PostgreSQL仓储、任务租约、文件存储。
- 契约测试：OpenAPI及Dify JSON Schema。
- 端到端测试：上传、解析、分类、审核、复核、导出和失败重试。

骨架阶段先覆盖健康接口、API响应约定和JSON Schema合法性。

案例库自动入库验收条件：

- `run_filter.py 30` 保存 `case.csv` 后自动入库，重复标题和链接不重复插入。
- 入库失败返回错误并保留生成文件，可单独重试 CSV 入库。
- 前端只查询数据库，保留日期分组、案例卡片和原文链接，无上传或同步操作。
- 数据库查询失败明确显示错误；空库正常显示空状态，不读取旧上传索引。
- 导入端与查询端统一使用 `CASE_DB_NAME` 指定数据库。
