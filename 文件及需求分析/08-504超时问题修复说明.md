# 合同智审 504 超时问题修复说明

## 问题描述

用户在进行合同智审时，出现以下错误：

```
合同智审 Dify 调用失败: HTTP 504: <html>
<head><title>504 Gateway Time-out</title></head>
<body>
<center><h1>504 Gateway Time-out</h1></center>
<hr><center>nginx/1.29.1</center>
</body>
</html>
```

## 根本原因

504 Gateway Time-out 错误表明 Nginx 网关在等待 Dify 服务响应时超时。原因如下：

1. **客户端超时设置过短**：原代码设置的超时时间为 180 秒（3分钟）
2. **合同智审处理时间长**：AI 模型分析合同文档、提取风险点、生成建议需要较长时间
3. **网关超时限制**：Dify 服务前端的 Nginx 网关可能有自己的超时限制
4. **缺少细分超时配置**：原配置只有总超时和连接超时，没有区分读取和写入超时

## 修复方案

### 1. 增加 Dify 合同智审超时时间

**位置**：`services/api/app/main.py:204-206`

**修改前**：
```python
timeout = httpx.Timeout(180.0, connect=20.0)
```

**修改后**：
```python
# 增加超时时间：合同智审可能需要较长处理时间
# 连接超时 30 秒，读取超时 600 秒（10 分钟），写入超时 60 秒
timeout = httpx.Timeout(600.0, connect=30.0, read=600.0, write=60.0)
```

**改进说明**：
- **总超时**：180秒 → 600秒（10分钟），给 AI 模型足够的处理时间
- **连接超时**：20秒 → 30秒，应对网络不稳定情况
- **读取超时**：新增 600秒，明确指定等待 Dify 响应的最长时间
- **写入超时**：新增 60秒，用于上传合同文件

### 2. 增加金蝶案例存储超时时间

**位置**：`services/api/app/main.py:311`

**修改前**：
```python
async with httpx.AsyncClient(timeout=httpx.Timeout(180.0, connect=20.0)) as client:
```

**修改后**：
```python
# 增加超时时间以处理大文件上传
async with httpx.AsyncClient(timeout=httpx.Timeout(300.0, connect=30.0, read=300.0, write=120.0)) as client:
```

**改进说明**：
- **总超时**：180秒 → 300秒（5分钟）
- **连接超时**：20秒 → 30秒
- **读取超时**：新增 300秒
- **写入超时**：新增 120秒，应对大文件上传场景

## 技术细节

### httpx.Timeout 参数说明

```python
httpx.Timeout(
    timeout,      # 总超时时间（秒）
    connect,      # TCP 连接超时（秒）
    read,         # 读取响应超时（秒）
    write         # 写入请求超时（秒）
)
```

- `timeout`：整个请求的最大时间限制
- `connect`：建立 TCP 连接的最大时间
- `read`：等待服务器响应数据的最大时间（关键！）
- `write`：发送请求数据的最大时间

### 为什么需要 600 秒读取超时？

合同智审的处理流程：
1. 上传合同文件到 Dify（约 5-10 秒）
2. Dify 提取文档文本（约 10-30 秒）
3. AI 模型分析合同内容（约 2-8 分钟）
4. 生成风险点和建议（约 1-2 分钟）
5. 返回结构化结果（约 1-5 秒）

总计可能需要 **3-10 分钟**，因此设置 600 秒（10 分钟）是合理的。
